# Rule-Based AI Chatbot 🤖

A simple, interactive rule-based chatbot built in Python as part of the **CodeAlpha Internship (Task 2)**. The chatbot uses predefined rules, keyword matching, and regular expressions to interact with users, respond to common queries, and handle basic conversational flows.

---

## 📌 Features

- **Keyword & Pattern Matching:** Recognizes user intent based on predefined rules and keyword triggers.
- **Natural Responses:** Provides friendly answers for common topics like greetings, FAQs, time/weather inquiries, and general help.
- **Case-Insensitive Input:** Processes user messages regardless of uppercase or lowercase input.
- **Fallback Handling:** Gracefully handles unknown queries with default fallback responses.
- **Interactive CLI Interface:** Runs smoothly in any terminal/command prompt.
- **Easy Customization:** Straightforward rule structure allowing quick addition of new intent-response pairs.

---

## 🛠️ Tech Stack & Prerequisites

- **Language:** Python 3.x
- **Libraries Used:** Standard Python Libraries (`re`, `sys`, `random` - no external dependencies required)
